------

## 大头特效

类似抖音：

```text
正常
   O

大头
  OOO
```

不能简单：

```js
ctx.scale(1.5)
```

这样会把全身放大。

必须：

```text
识别人头区域
    ↓
局部放大
    ↓
边缘融合
```

推荐：

### WebGL Mesh Warp

或者

### WebGPU Mesh Warp

实现：

```text
人脸关键点
    ↓
构建三角网格
    ↓
移动顶点
    ↓
GPU重绘
```

原理类似：

```text
Snapchat
TikTok
Instagram
```

滤镜。

# 哪些需求不建议纯浏览器做

```text

60fps
```

纯浏览器：

```text
内存爆炸

导出失败
```

不建议。

------

### AI换脸

例如：

```text

```

虽然 ONNX Runtime Web + WebGPU 可以做，但：

```text
模型很大
100MB+
```

用户体验差。

建议后端。

### AI视频生成

例如：

```text
图片生成视频
```

浏览器目前不现实。

必须云端。
